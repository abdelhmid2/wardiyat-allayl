مواقيت الصلاة — القاهرة

محسوبة فلكيًا كل يوم لمدينة القاهرة (بمعيار الهيئة المصرية العامة للمساحة: الفجر ١٩٫٥° والعشاء ١٧٫٥°)، وتتحدث تلقائيًا مع العدّاد التنازلي للصلاة القادمة.

تنبيه: المواقيت حساب فلكي تقريبي للاسترشاد، وقد تختلف دقائق بسيطة عن المواقيت الرسمية المعلنة في منطقتك — راجع النتيجة الرسمية عند الحاجة.

الترتيب — الأكثر تسبيحًا واستخدامًا

الترتيب بيبدأ فاضي تمامًا، وبيظهر فيه فقط مستخدمون حقيقيون سجّلوا حساباتهم بالإيميل وسبّحوا أو كتبوا فعلًا: كل تسبيحة = نقطة، وكل رسالة في الشات = ٥ نقاط. الترتيب محفوظ في قاعدة بيانات Firebase ومشترك بين كل المستخدمين على كل الأجهزة، وصاحب المركز الأول بيظهر على القمة هنا.

👑
الترتيب فاضي — لسه محدش سبّح أو كتبسجّل دخولك بالإيميل في قسم الشات، وابدأ التسبيح من السبحة فوق، واسمك هيظهر هنا بنشاطك الحقيقي بس.

    التسجيل والشات الجماعي

    سجّل حسابك بالإيميل وكلمة السر، وبعدها هتقدر تشارك في الشات الجماعي الحقيقي: الرسائل بتتحفظ في قاعدة بيانات Firebase وبتظهر لكل المستخدمين على كل الأجهزة، واسمك بيظهر في الترتيب بنشاطك الحقيقي بس.

    ؟
    سجّل دخولك بالإيميل عشان تشوف الشات الجماعي وتشارك فيه.
    الشات بيبدأ فاضي تمامًا، وبيظهر فيه فقط رسائل حقيقية كتبها مستخدمون حقيقيون، وبتتحفظ وبتوصل لكل المستخدمين على كل الأجهزة.
    🔐 لصاحب المشروع: قواعد Firestore المطلوبة عشان الشات والترتيب يشتغلوا

    قاعدة بيانات مشروع wardiyat-allayl شغالة في وضع الإنتاج، فهي بترفض أي قراءة أو كتابة لحد ما القواعد دي تتنشر. من غيرها الشات والترتيب مش هيشتغلوا، وبمجرد نشرها هيشتغلوا فورًا من غير أي تغيير في الموقع:

    1. افتح Firebase Console وادخل مشروع wardiyat-allayl.
    2. من القائمة اختار Build ← Firestore Database، وبعدين تبويب Rules.
    3. امسح القواعد الموجودة والصق القواعد دي مكانها بالكامل.
    4. دوس Publish، وبعدين حدّث صفحة الموقع هنا — الشات والترتيب هيشتغلوا على طول.
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Users & ranking: any signed-in user can read.
    // Each user can create and update only their own document.
    match /users/{userId} {
      allow read: if request.auth != null;
      allow create, update: if request.auth != null && request.auth.uid == userId;
      allow delete: if false;
    }

    // Group chat messages: any signed-in user can read.
    // A user can only send a message under their own uid,
    // and no message can be edited or deleted afterwards.
    match /messages/{messageId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.text is string
        && request.resource.data.text.size() > 0
        && request.resource.data.text.size() <= 300;
      allow update, delete: if false;
    }
  }
}

    القواعد دي آمنة: محدش يقدر يقرأ الشات أو الترتيب من غير ما يسجّل دخوله، وكل مستخدم يقدر يعدّل ملفه ونقاطه هو بس، ومفيش أي حد يقدر يعدّل أو يمسح رسالة بعد ما اتبعتت.
